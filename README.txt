THE EVERYDAY TABLE - Five page school website

Open index.html to preview the website locally.

Pages: Home (index.html), Recipes (recipes.html), Meal Prep (meal-prep.html), Cooking Tips (tips.html), About (about.html).

Publish for free with GitHub Pages:
1. Create a free GitHub account at github.com.
2. Create a new PUBLIC repository named everyday-table.
3. Upload all five .html files and the entire assets folder (not the ZIP itself).
4. Open repository Settings > Pages > Build and deployment > Deploy from a branch. Choose main and / (root); Save.
5. Copy the website URL shown under Settings > Pages and submit that URL to your teacher.

The artwork and logo were created for this student project. Fonts: Playfair Display and DM Sans, with local fallbacks.
